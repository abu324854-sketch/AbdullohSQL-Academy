3. SQL Injection Kiber-Laboratoriyasi

Xaker kiritmasi (' OR '1'='1) oddiy kodni va Prepared Statementni qanday ta'sirlashini sinang.

❌ Zaif kod (String Concatenation):
SELECT * FROM users WHERE email = '' OR '1'='1';
🛡️ Himoyalangan (Prepared Statement):
SELECT * FROM users WHERE email = $1; -- [$1 = "' OR '1'='1"]

3D Relyatsion Arxitektura

3D fazoda chap tomonda talabalar jadvali, o'ng tomonda kurslar jadvali joylashgan. Yorqin neon chiziqlar PRIMARY KEY va FOREIGN KEY bog'lanishlarini ko'rsatadi.

SQL So'rov:
SELECT t.ism, k.nomi
FROM talabalar t
JOIN buyurtmalar b ON t.id = b.talaba_id
JOIN kurslar k ON k.id = b.kurs_id;
